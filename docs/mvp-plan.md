# 小说阅读器 MVP 规划

> 更新时间：2026-09-01

## 目标

MVP 只解决一个闭环：**打开本地 TXT 文件 → 正常阅读 → 记住阅读进度**。

## MVP 功能范围

| 模块 | 功能 | 说明 |
| --- | --- | --- |
| 文件导入 | 文件选择器 + 拖拽导入 TXT | 必做 |
| 编码处理 | 自动识别 UTF-8 / GBK / GB18030 | 必做，中文 TXT 常见 GBK 编码 |
| 编码切换 | 识别错误时手动切换编码 | 必做，兜底手段 |
| 章节解析 | 识别章节标题，生成目录 | 必做 |
| 阅读界面 | 正文渲染、上一章/下一章、目录跳转 | 必做 |
| 阅读设置 | 字号、行距、页宽、日间/夜间主题 | 必做 |
| 进度记忆 | 自动保存并恢复阅读位置 | 必做 |

## 明确不做（留待 V1+）

- EPUB / PDF / MOBI 等其他格式
- 大文件专项优化（普通小说通常小于 10 MB，无需虚拟滚动）
- 全文搜索
- 书签、批注、云同步、在线书库
- 分页仿真翻页、TTS 朗读

## 技术选型

- 纯前端 Web 应用：Vite + Vue 3 + TypeScript，无后端
- 浏览器 File API 读取本地文件，无需服务端
- 测试：Vitest + @vue/test-utils + jsdom
- 后续如需桌面应用，可用 Tauri 2 直接包装，核心解析代码可复用

## 目录结构

```
novel-reading/
  docs/
    mvp-plan.md
  src/
    core/              # 纯逻辑：编码检测、章节解析、进度存储
    components/        # Reader / TocPanel / SettingsPanel / FileDrop
    views/             # 页面级组件
    store/             # 阅读状态管理
    utils/
  tests/
    unit/              # 单元测试与小说样例 fixture
  index.html
  package.json
  vite.config.ts
  tsconfig.json
  .gitignore
```

核心解析逻辑与 UI 分离，便于单独测试与后续复用。

## 里程碑

- **M0 初始化**：Vite + Vue 3 + TS + Vitest 脚手架与测试环境
- **M1 解析核心**：编码检测 + 章节解析 + 完整单元测试
- **M2 阅读主流程**：打开文件 → 渲染正文 → 阅读设置
- **M3 阅读体验**：目录、上下章、进度记忆与恢复
- **M4 打磨验收**：错误提示、主题细节、README 与文档

## 质量约定（遵循 AGENTS.md）

- 每次改动必须编写或更新相关测试，交付前全部测试通过
- 小步提交，一次提交只做一件事
- 敏感信息不入库，必要时补充 .gitignore

## 风险与对策

- 编码误判：提供手动切换编码的兜底入口
- 大段落渲染卡顿：按章节分块渲染
- 进度错乱：以文件内容 hash 关联进度
