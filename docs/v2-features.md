# novel-reading v2 功能清单

> 起草：2026-09-15。用途：个人自用，不面向商业分发。整体交付形态与里程碑见 [`v2-plan.md`](v2-plan.md)。
> 要求: 舒适的阅读体验至上

## 协作方式

- 按照ABCD顺序实现:完成一项 → 自测通过 → **你在浏览器里点一遍验收** → 提交 git → 下一项。
- 交付形态默认：构建成**单个 HTML 文件**，双击用浏览器打开，无 .NET / WebView2 / 安装步骤，断网可用。
- 优先级：P0 是「缺了就没法用」的闭环，P1 是「长期读下去必须舒服」，P2 是锦上添花。

## A. 地基（P0）

| 编号 | 功能 | 说明 | 验收 | 量级 |
| --- | --- | --- | --- | --- |
| A1 | 单文件产物 | 构建出 1 个内联全部资源的 HTML，无外部请求 | 双击打开、断网仍可用 | S |
| A2 | 打开一本 TXT | 拖拽进窗口 + 文件选择按钮两种入口 | 只考虑小文件 立即出现正文 | S |
| A3 | 记住上次这本书 | 书内容存本地（IndexedDB），下次打开自动回到这本书，不用重选文件 | 关掉→重开→直接继续读 | M |
| A4 | 进度记忆 | 记录到「章节 + 段落锚点」，而不是只记章节 | 读到中段关闭，重开后位置误差不超过一屏 | M |

## B. 读取核心（P0）

| 编号 | 功能 | 说明 | 验收 | 量级 |
| --- | --- | --- | --- | --- |
| B1 | 编码识别与切换 | UTF-8 / GBK / GB18030 自动识别；错了可手动切，切换后阅读位置不丢 | 用 GBK 与 UTF-8 各一本，正文都不乱码 | M |
| B2 | 章节解析 | 支持「第一章 / 第1章 / 第一百二十三章 / 卷一 / Chapter 1」等常见写法；认不出时退化为按固定长度分节，而不是直接报错 | 用 3 本真实小说验证目录完整 | M |
| B3 | 目录 | 侧边目录列表，当前章节高亮，点击跳转 | 点第 5 章直接到位 | S |
| B4 | 正文排版 | 缩进、段间距、行距、页宽、字体、字号 | 连读 10 分钟不觉得挤或松 | M |
| B5 | 导航 | 上一章 / 下一章按钮；键盘 ←/→ 翻章、空格与 PageUp/PageDown 翻页、Home/End 到首尾 | 手不用离开键盘就能读完一章 | S |
| B6 | 位置提示 | 底部显示「第 x/y 章 · 全书 z%」 | 与实际内容相符 | S |

## C. 阅读体验（P1）

| 编号 | 功能 | 说明 | 验收 | 量级 |
| --- | --- | --- | --- | --- |
| C1 | 主题 | 日间 / 夜间 / 护眼（纸色），可选跟随系统 | 不影响正常阅读体验 | S |
| C2 | 沉浸模式 | 工具栏可隐藏，鼠标靠近顶部/底部才出现；配合 F11 全屏 | 平时只剩正文 | S |
| C3 | 设置持久化 | 字号、行距、页宽、字体、主题、编码选择都记住 | 重开后设置不变 | S |
| C4 | 连续阅读 | 读到章末继续滚动自动进入下一章，滚动条不跳动 | 连读 3 章不用点按钮 | M |
| C5 | 最近打开列表 | 多本书的书名、进度、上次时间，一键继续 | 两本交替读，切换不掉进度 | M |
| C7 | 书签 | 快捷键加书签 + 书签列表跳转 | 能持久化 | S |

## D. 增强（P2，按需，可后置或删除）

| 编号 | 功能 | 说明 |
| --- | --- | --- |
| D1 | 文件夹导入 | 一次导入一个文件夹里的全部 TXT，列表中选择 |
| D2 | 书架 | 可将txt文件保存在书架文件中 |
| D3 | 全文搜索 | 全书关键词搜索，结果列表可跳转（大文件需注意性能） |
| D4 | 备份 / 恢复 | 把书、进度、书签、设置导出成一个文件，换机导入 |
| D5 | 自动阅读 | 打开后自动滑动阅读,可设置速度 |

## E. 明确不做

EPUB / PDF / MOBI、账号与云同步、在线书城、批注与笔记导出、多设备同步、大文件专项优化（>50 MB 且卡顿再议）、TTS 朗读（可后议）。
